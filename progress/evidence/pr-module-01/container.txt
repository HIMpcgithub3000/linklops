=== a real defect found by checking rather than assuming ===
  The first .dockerignore said '.env'. That pattern matches only the context
  ROOT. The real file is api/.env, so 'COPY api/ ./' shipped live database
  credentials into an image layer. Confirmed by grepping the built image:
  DATABASE_URL and MIGRATION_DATABASE_URL both present, both with passwords.
  Layers are immutable, so a later RM would not have removed it -- anyone
  who pulls the image can read a 'deleted' file. Fixed to **/.env and
  !**/.env.example, rebuilt, re-checked: .env absent, contract still present.
